# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] - 2026-08-25

### Added

- **DXF export for Voronoi patterns.** New "Export DXF..." button on the
  Voronoi page opens a native save dialog (via `rfd`) and writes the generated
  pattern to disk. The button stays disabled until a pattern has been
  generated.
- **Dependency-free DXF writer** (`src/dxf_export.rs`). Emits AutoCAD R12
  (AC1009) ASCII with closed `POLYLINE`/`VERTEX`/`SEQEND` entities on a
  dedicated `VORONOI` layer, chosen for maximum compatibility with Inventor,
  FreeCAD, LibreCAD, and CAM packages. Coordinates are Y-flipped from screen
  space so exported parts are not mirrored.
- **Cell spacing.** The "Space between cells" slider is now wired up, insetting
  each cell toward its centroid by half the slider value. Cells too small to
  inset are dropped rather than emitted inverted.
- `voronoi_polygons()` exposes raw cell outlines, so the live preview and the
  DXF export derive from a single source of geometry and cannot drift apart.

### Changed

- **Migrated from the `voronoi` crate to `voronoice`.** The previous crate
  clipped to a square box only and could not associate cells with their
  generating sites. `voronoice` supports true rectangular bounding boxes, so
  non-square canvases now generate correctly.
- Dropped the `ordered_float` dependency — `voronoice::Point` uses plain `f64`.
- Isosceles triangle result text now uses the same `+ 3px` font size as the
  rest of the results, instead of only the first line.

### Fixed

- **Voronoi preview rendered every cell stacked on top of each other.** Each
  `Path` was independently scaling its commands to fill the preview area. Added
  a shared viewbox in millimetre space so cells tile in one coordinate system.
- **Voronoi callbacks never reached Rust.** `submit-voronoi` and
  `voronoi-cells` were declared only on the page component; Slint generates
  Rust accessors solely for the exported top-level component. They are now
  forwarded through `AppWindow`.
- **Isosceles tab drew its Clear button, inputs, and results on top of one
  another.** The enclosing `VerticalBox` closed after the Clear button row,
  leaving the remaining rows as direct children of `Tab`, which stacks children
  at a single origin instead of laying them out.
- Renamed the Voronoi `width` and `height` `LineEdit` elements to
  `width-input` / `height-input`, which were shadowing the built-in geometry
  properties present on every element.
- Capped the "Min cell edges" slider at 10. It filters on cell vertex count,
  and real Voronoi cells rarely exceed ~10 vertices, so higher values silently
  blanked the entire preview.

### Known limitations

- The Voronoi `seed` parameter drives both the RNG state and the point count,
  so adjusting it changes cell density as well as layout. Splitting these into
  separate controls is still open.
- DXF output is unitless (R12 has no `$INSUNITS`); import as millimetres.
