# Release v0.1.0 — Cross-Platform Production Release

A sleek, lightweight desktop utility designed to accelerate engineering and geometry calculations for CAD and fabrication workflows. Built entirely in **Rust** and powered by the **Slint UI** toolkit for native, hardware-accelerated performance.

### 🚀 What's New & Key Features

*   **Advanced Force & Pressure Calculator:** Compute mechanical forces and instantly evaluate structural pressure outputs in MPa.
    *   Supports dynamic unit conversions across various Mass, Area, and Force scales.
    *   Ensures mathematically precise pressure derivations:
        $$\text{Pressure (MPa)} = \frac{\text{Force (N)}}{\text{Area (mm}^2\text{)}}$$
*   **Geometry & Spacer Helpers:** Built-in utilities to quickly solve geometric layouts and structural hardware alignments.
*   **Polished Desktop Integration:** Native windowing, system font rendering, and clean launcher shortcuts across Windows and Linux.

### 📦 Installation & Packages

#### 🪟 Windows
*   **File:** `cad-helper-3d-setup.exe`
*   **Installation:** Simply download and run the setup wizard. It will install the application natively and add a desktop/start menu shortcut.

#### 🏔️ Arch Linux / CachyOS
*   **File:** `cad-helper-3d-0.1.0-1-x86_64.pkg.tar.zst`
*   **Installation:** Download the package and install it securely using `pacman`:
    ```bash
    sudo pacman -U cad-helper-3d-0.1.0-1-x86_64.pkg.tar.zst
    ```

#### 🌀 Debian / Ubuntu / Mint
*   **File:** `cad-helper-3d_0.1.0_amd64.deb`
*   **Installation:** Download the deb package and install it using `apt` or `dpkg`:
    ```bash
    sudo apt install ./cad-helper-3d_0.1.0_amd64.deb
    ```
