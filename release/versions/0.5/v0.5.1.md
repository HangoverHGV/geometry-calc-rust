# Print Orientation — Changes

Adds Portrait / Landscape selection to the batch PDF printing in CAD Helper 3D. The orientation is stored as a Slint property and passed into a winprint `PrintTicket` when printing.

Files touched:

1. `app_window.slint` (the main UI file)
2. Printer UI setup (`setup_ui_printers` / `open_file_dialog`)
3. `batch_printing.rs`

---

## 1. `app_window.slint`

### Keep the enum (already present)

```slint
export enum PrintOrientation { portrait, landscape }
```

### Add a property in the Printing section

```slint
//Printing
in-out property <[PrinterItem]> printers-list;
in-out property <string> active-printer: "";
in-out property <PrintOrientation> print-orientation: PrintOrientation.portrait;
//                  ###
```

### Remove the callback

```diff
- callback chose_orientation(PrintOrientation);
```

### Replace the Orientation menu

```slint
Menu {
    title: "Orientation";
    MenuItem {
        title: "Portrait";
        checkable: true;
        checked: root.print-orientation == PrintOrientation.portrait;
        activated => { root.print-orientation = PrintOrientation.portrait; }
    }
    MenuItem {
        title: "Landscape";
        checkable: true;
        checked: root.print-orientation == PrintOrientation.landscape;
        activated => { root.print-orientation = PrintOrientation.landscape; }
    }
}
```

> If the check mark stops following the property after the first click, the checkable item overwrote the `checked` binding. Remove `checkable: true` and keep only `checked:`.

## 3. `batch_printing.rs` (full file)

```rust
use std::path::Path;
use winprint::printer::{FilePrinter, PdfiumPrinter, PrinterDevice};
use winprint::ticket::{
    FeatureOptionPackWithPredefined, PredefinedPageOrientation, PrintCapabilities,
    PrintTicket, PrintTicketBuilder,
};
use crate::PrintOrientation;

pub fn get_all_printers() -> Result<Option<Vec<String>>, String> {
    let devices = match PrinterDevice::all() {
        Ok(devs) => devs,
        Err(e) => return Err(format!("Failed to fetch Windows printers: {}", e)),
    };

    if devices.is_empty() {
        return Ok(None);
    }

    let printer_names: Vec<String> = devices
        .into_iter()
        .map(|device| device.name().to_string())
        .collect();

    Ok(Some(printer_names))
}

fn build_ticket(
    device: &PrinterDevice,
    orientation: PrintOrientation,
) -> Result<PrintTicket, String> {
    let wanted = match orientation {
        PrintOrientation::Portrait => PredefinedPageOrientation::Portrait,
        PrintOrientation::Landscape => PredefinedPageOrientation::Landscape,
    };

    let capabilities = PrintCapabilities::fetch(device)
        .map_err(|e| format!("Failed to read printer capabilities: {:?}", e))?;

    let orientation_option = capabilities
        .page_orientations()
        .find(|o| o.as_predefined_name() == Some(wanted))
        .ok_or_else(|| format!("Printer does not support {:?} orientation", wanted))?;

    let mut builder = PrintTicketBuilder::new(device)
        .map_err(|e| format!("Failed to create print ticket: {:?}", e))?;
    builder
        .merge(orientation_option)
        .map_err(|e| format!("Failed to set orientation: {:?}", e))?;
    builder
        .build()
        .map_err(|e| format!("Failed to build print ticket: {:?}", e))
}

pub fn print_files(
    printer_name: &str,
    files: Vec<String>,
    orientation: PrintOrientation,
) -> Result<usize, String> {
    let devices = PrinterDevice::all()
        .map_err(|e| format!("Failed to fetch Windows printers: {}", e))?;

    let selected_device = devices
        .into_iter()
        .find(|dev| dev.name() == printer_name)
        .ok_or_else(|| format!("Printer '{}' not found in Windows devices.", printer_name))?;

    // Must happen before PdfiumPrinter::new, which takes ownership of the device
    let ticket = build_ticket(&selected_device, orientation)?;

    let pdf_printer = PdfiumPrinter::new(selected_device);
    let mut failed_count = 0;
    let total_files = files.len();

    for file in &files {
        let path = Path::new(file);
        if let Err(e) = pdf_printer.print(path, ticket.clone()) {
            eprintln!("Failed to print {}: {:?}", file, e);
            failed_count += 1;
        }
    }

    if failed_count > 0 {
        Err(format!(
            "Completed with errors: {} out of {} files failed to print.",
            failed_count, total_files
        ))
    } else {
        Ok(total_files)
    }
}
```

### What changed in `print_files`

- `orientation: PrintOrientation` is a new parameter (it was referenced but never declared).
- The unused `landscape` bool is gone.
- `Default::default()` is replaced with a `PrintTicket` that carries the chosen orientation.
- The ticket is built before `PdfiumPrinter::new`, because that call takes ownership of the `PrinterDevice`.

## Possible compile issues

| Error | Fix |
|---|---|
| `PredefinedPageOrientation::Portrait` / `Landscape` not found | Check the variant names with IDE autocomplete on `PredefinedPageOrientation` (not verified against winprint 0.2.1 docs). |
| `PrintTicket` doesn't implement `Clone` | Call `build_ticket` inside the loop. That needs a device per iteration, so create the `PdfiumPrinter` per file as well. |
| "Printer does not support … orientation" at runtime | Some drivers don't advertise both options. Fall back to `Default::default()` instead of returning an error. |
| Landscape PDF still comes out rotated | Pdfium may auto-rotate to fit the PDF's own page size. Check the source PDF's page dimensions. |
